# Task Manager API

## Features
- User Authentication
- Task CRUD
- Filtering
- Indexing optimization
- In-memory caching
- Secure env config
- Cloud deployment
- REST API

## API Endpoints

### Register
POST /register
Body:
{
  "email": "test@test.com",
  "password": "123456"
}

Response:
{
  "message": "User created"
}
